# Exovon Plugin for Antigravity

Integrates Exovon Cloud Platform deployment tools and ExoStore PostgreSQL querying into Google Antigravity.

## Tools Provided

* `exovon_deploy` — Packages code and dispatches build pipelines or static promotions.
* `exovon_get_logs` — Streams real-time build compiler and container logs.
* `exovon_status` — Reports project health, deployment URL, and routing status.
* `exovon_rollback` — Reverts edge traffic to a previous deployment.
* `exovon_database_query` — Executes parameterized SQL on ExoStore PostgreSQL.
